# Nadar por la gloria

Jueguito de carreras de natación para el grupo, compañero de [Nadamos por la milanga](https://matiasslopez.github.io/nadamos-por-la-milanga/). Se juega en el celu o en la compu.

Tres modos: sprint (50 m), ida y vuelta (200 m con vueltas americanas) y aguas abiertas (500 m con corriente). Elegís tu nadador y el azar sortea dos rivales.

Hecho con ayuda de Claude.
